# 候选范围

本项目整理单视频、单曲和平台直播间的解析算法、返回模型、本机网页、最小调用示例及离线测试。

纳入：B站普通视频、抖音视频；网易云/QQ音乐/酷狗单曲；B站/抖音/虎牙/斗鱼直播间。URL 识别、平台元信息、必要签名、媒体地址及播放条件属于解析范围。

明确排除：歌单、收藏、批量导入、连播列表、电台、定时生成、播放队列、上传转码、文件管理、API 中转、Minecraft、用户账号/后台/档位、统计、备份、公网部署系统、私有节点与控制通道。未复制原网站 HTML、主题、扩展、Overlay、媒体/WASM 或运维档案。

本机网页是作者新增授权的本地使用入口，仅绑定 `127.0.0.1` 并调用本库 `parse_one`，不转发媒体、不开设远程 API。好友按钮只通过普通导航打开作者指定的网站，不发送本地输入、Cookie 或解析结果。本地安装与使用说明属于此次范围。

暂未纳入番剧、动漫站和 YouTube；这些不在本次独立单链接实现清单中。直接媒体 URL 透传也没有做成通用下载/代理入口。

网易云/QQ音乐/酷狗原文件里的歌单识别、歌单请求和列表返回代码已经从候选移除。原应用与历史不会随新仓库一起导入。

边界限制：QQ音乐只提供独立直连单曲流程；酷狗基础查询不带原应用的签名常量。B站输出的 DASH 元数据不包含合流、缓存或持续续签服务。直播部分只返回平台媒体地址，不包含推流接入、媒体服务器或本地播放控制。

公开仓库中的 `export-manifest.json` 是本候选的文件白名单和内容摘要，`tools/check_export.py` 可重新检查文件完整性、链接/额外文件和明显的私人应用依赖；它不是完整的秘密或法律审计证明。
