# 单链接解析原理

## 统一流程

完整链接 → 精确平台域名匹配 → 拒绝歌单/批量链接 → 解析媒体 ID 或直播间 → 请求平台元数据/播放接口 → 检查状态与必要签名 → 返回 `ParseResult`。

`parse_one` 使用显式解析器白名单，每次调用独立会话、超时和有限重定向，不读取整站配置、数据库或凭据库。调用者可以自行向相应平台传入其有权使用的 Cookie。平台签名、临时 URL 和 Cookie 的用途不同，返回的 URL 不代表永久播放权限。

## B站普通视频

1. 从 BV/av 链接提取标识；短链先展开。
2. 请求 `x/web-interface/view`，取得 cid、标题、作者与封面。
3. 普通模式尝试 HTML5 playurl，然后尝试常规 playurl；WBI 路径需从 nav 响应取得动态 key、按混排表生成 mixin key、参数排序及过滤后生成 MD5 `w_rid`。
4. 对平台给出的主备 URL 做 CDN 域名筛选和有时限的线路探测。
5. 账户模式只使用调用者提供的 Cookie，并检查登录状态；DASH 模式额外选择 H.264 视频和音频地址，保持音视频分离。

返回平台地址和必要 Referer。候选不保存代理 token、不写 Redis、不续签长时播放上下文、不下载或合流。可用清晰度受账户、内容及平台返回限制。

## 抖音单视频

展开分享短链 → 从最终地址/跳转历史提取视频 ID → 依次读取分享页 `_ROUTER_DATA`、网页详情接口或详情页数据 → 从视频对象选择地址、标题和封面。保留原实现的有限重试；地址中的 `playwm` 路径按原实现归一化为 `play`。不能把这种参数处理理解为永久下载或版权授权。

## 网易云单曲

展开单曲短链、提取歌曲 ID → 请求歌曲播放地址与元信息 → 按实现中的音质顺序选择平台实际返回的 URL → 无可用地址或受限时明确失败。单曲凭据通过参数提供，不包含登录、账户绑定、会员管理、歌单枚举或歌单歌曲提取。

独立库直接返回核验过的播放接口 URL，不沿用原网站依靠后续流程补全的通用 outer/url 入口。签名地址可能绑定调用时出口 IP，调用端应在相同网络条件下检查播放；本库不承担跨出口重签或代理。

## QQ音乐单曲

从分享链接/页面识别 songmid → 根据调用者 Cookie 提取 UIN 并请求 vkey 数据 → 主接口失败时尝试基础单曲接口 → 获得地址后再请求歌曲元数据。vkey 分支将平台媒体服务地址与 purl 组合，回退分支使用接口直接返回的 URL；两者均无地址时明确失败。

这是独立服务器直连的单曲流程。原站用于改善可用性的私人节点注册、任务投递和结果回传没有包含在本仓库；需要不同网络出口时由使用者自行评估，不承诺原站成功率。

## 酷狗单曲

从链接或页面提取歌曲 hash（及可选 album_id）→ 请求基础歌曲信息/播放地址 → 无地址时按 hash 与协议参数查询 tracker 回退 → 返回单曲 URL。Cookie 只由调用者传入对应平台的查询，不向 tracker 回退发送。

`sign_parameters(params, salt)` 展示原协议的参数排序、过滤与首尾 salt 的 MD5 计算方式；salt 由调用者提供，不内置原应用常量，基础查询流程不使用这段签名。完整会员签名网关、私人 Cookie 提取和所有歌单方法均未包含。

## 平台直播间

| 平台 | 元信息与地址流程 |
| --- | --- |
| B站 | 房间信息接口判断开播状态，取得真实房间号，再请求 H5 播放接口得到平台 HLS |
| 抖音 | 访问直播页获取临时 ttwid，向房间进入接口提交浏览器参数，检查开播状态后选择 FLV 清晰度 |
| 虎牙 | 数字房间或页面别名解析，读取公开房间数据，按平台 HLS 清单与线路优先级选择合法且未过期的 HLS 地址；保留有界清单解析辅助 |
| 斗鱼 | 房间信息 → 获取动态加密参数 → 在本地按次数迭代 MD5 → 请求平台换链接口 → 校验媒体 CDN/格式；不执行远程混淆 JavaScript |

直播 URL 仍由平台提供并可能过期。辅助 HLS 清单解析不构成持续媒体代理；不会代替使用者维持播放连接、录制或转码。

## 安全与测试范围

库入口限制平台域名、IP 字面量、凭据型 URL、端口及批量路径；请求会话不继承系统代理，限制重定向次数。含 Cookie 或 Authorization 的请求必须使用 HTTPS，首次请求和重定向均检查，不依赖平台收到 HTTP 后再升级。它没有实现 DNS 固定或面向多租户公网服务的完整网络隔离，不能直接把任意输入包成公开解析 API。

本候选的回归使用合成 JSON/HTML、假 Cookie 和 MockTransport，只检查算法与失败处理，没有真实平台访问或播放验收。不要把平台签名示例或 fixtures 当作真实凭据使用。

## 本机网页

`python -m vrc_parsers.web` 运行标准库 HTTP 服务，只绑定回环地址，静态页面使用同源请求调用一次 `parse_one`。页面数据在内存中处理；本进程随机令牌、Host/Origin 校验、JSON 正文上限和单次并发限制保护本机入口，不允许跨站调用或文件目录浏览。

本机服务仅返回解析结果，不代理平台音视频，不保存 Cookie，不提供账号/歌单/多人会话。好友入口是普通外链导航，不附加本地数据。运行和停止方式见 [使用指南](LOCAL_USE.md)。
